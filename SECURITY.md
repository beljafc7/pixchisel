# Security Policy

## Supported versions

The latest published PixChisel release receives security updates. Pre-release
versions may change quickly and should not be treated as long-term support
releases.

## Reporting a vulnerability

Please do not disclose suspected vulnerabilities in a public issue.

Use
[GitHub Security Advisories](https://github.com/beljafc7/pixchisel/security/advisories/new)
to submit a private report. Include the affected version, operating system,
reproduction steps, potential impact, and any proposed mitigation.

Reports will be reviewed before public disclosure. Confirmed issues will be
coordinated through a security advisory and a corrected release when possible.
